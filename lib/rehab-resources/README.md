# 復健科補助與援助資源

此目錄為 `/rehab-resources` 的公開靜態資料，不儲存患者資訊，也不執行補助審核。

## 收錄與更新

- `national.ts`：全國性政府、民間方案及服務入口。
- `central-government.ts`：彰化、南投、臺中、雲林政府方案。
- `central-community.ts`：中部基金會、慈善會與醫院方案／社工入口。
- `expanded-changhua-taichung.ts`、`expanded-nantou-yunlin.ts`：中部四縣市擴充的政府方案與服務。
- `expanded-central-community.ts`：擴充的中部民間及醫院方案與服務。
- `provider-hospitals.ts`、`provider-central-nonprofits.ts`、`provider-local-associations.ts`、`provider-supplement.ts`：以不同單位擴充的醫院、基金會及地方團體。
- `regional-contacts.ts`：22 縣市官方窗口；不計入補助方案數。
- `types.ts`：疾病、需求、地區及方案欄位。
- `matching.ts`：篩選、台灣日期、受理狀態及待複核判斷。
- `providers.ts`：將同一政府、基金會及單位的服務合併呈現及計數。

每個方案獨立記錄，區分現金補助、服務轉介及制度指引。引用可查閱的政府或機構第一手頁面，不因機構名稱推定全國服務，也不補造專款、資格或金額。來源暫時無法讀取時，須明示核對限制。

畫面與收錄目標以不同「單位」為準，不能以方案數充當單位數。同縣市政府各科室合併，同基金會各據點合併；已知受託單位有明確對應。不同服務仍保留各自的資格、窗口、狀態及來源，放在同一張單位卡片內。加入討論清單時保存該次符合條件的服務，列印依單位分組。

政府輔具及全台早療制度指引已移至「相關網頁」，不再以「各縣市政府」等非單一單位名稱列入結果。搜尋先呈現所選縣市實際服務，再列全國單位。若已選單位在其他查詢有新增服務，可合併加入原單位清單，不增加單位數。

`checkedAt` 是實際核對日期，`source.publishedOn` 是來源發布／修正日，`source.rocYear` 是來源適用年度；三者不可混用。完成內容核對才更新日期，部署或自動連結檢查不算內容核對。

`official-page` 為官網核對，`current-notice` 為當期公告核對，`contact-confirmed` 僅供實際取得窗口確認後使用；目前資料未聲稱已聯絡任何機構。

受理狀態無證據時用 `inquiry`。`ongoing` 只用於官方明確持續提供的服務／受理，`open` 須有當期公告及明確截止日。`startsOn`、`endsOn` 僅能使用公告確定的日期；分季核銷或事件發生後幾個月的相對期限寫在 `applicationPeriod`，不可將某季期限當成整個方案永久截止。

超過 `endsOn` 自動顯示已截止，不推定次年度延續。公告未開放的開始日到達後轉為需詢問，避免自動聲稱已開放。超過 `reviewAfterDays` 的開放／常態資訊轉為需詢問，其他狀態加待複核。這是前端顯示規則，沒有背景爬蟲、排程或自動機構查核。

建議早療與限期方案每月或更頻繁確認，常態窗口每季確認；年度換版、機構公告或連結失效時，優先重新核對。具體週期記錄在各筆資料。網站不會因此發送聯絡訊息。

本次擴充僅有官方索引內容、原頁與官方 PDF 均無法直接複核的醫院候選，先不納入公開清單；不可為達單位數目標降低核對標準。

## 篩選與隱私

畫面依序選擇疾病、查詢縣市、協助需求，三項皆完成並提交後才顯示結果。初始不顯示資源卡片、結果數或空白討論清單。修改條件時先返回步驟，重新提交才套用；已選資源保留，與新條件不符時明示差異。政府常用網站及 22 縣市窗口集中於頁面上方可展開的「相關網頁」，不計入方案數。

同欄複選為 OR，不同欄為 AND。通用資源保留於各病別結果；查詢縣市用於縮小地方候選，不代表使用者已具備該地戶籍、居住或就醫資格，也不寫入這些個人欄位。醫院候選仍需核對具體院所與院區。舊的個別地理條件匹配函式仍保留，未知戶籍或就醫地不能推定與居住地相同。

病名只作導覽，不等於身障、罕病、重大傷病或補助資格。年齡、證明與經濟資料僅作列印補充，不進行自動資格決定。篩選值及已選清單只在記憶體，不寫入 URL、localStorage、後端或分析事件。

頁尾資源連結停用預先載入，資源資料只屬於新頁面的程式包。頁面為 `force-static`，沒有新 API、資料庫、AI 呼叫或排程；列印與 PDF 儲存使用瀏覽器功能。資料變更經建置部署後才公開。

## 驗證

執行 `npm run test:resources` 檢查資料契約、22 縣市覆蓋、地區判斷、截止及複核規則。完整建置也會執行此測試。發布前再依專案 SEO 內容流程執行驗證、lint 與 build，並檢查手機與 A4 列印結果。
